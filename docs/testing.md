| そのまま使う | ホームの「提案を見る」→「そのまま使う」→ 再読み込み → 設定 | 「8月・9月の実績から」「2か月とも予算を超えていました（平均 ¥46,000）」「平均 ¥5,500 で、毎月 ¥9,500 ほど余っていました」と収入なしの説明が出る。反映後はカードが消え、再読み込みしても出ない。設定の予算が食費 46,000・娯楽 5,500 |
| 一部だけ変える | 「一部だけ変える」→ 娯楽のチェックを外す → 反映 | 食費だけ 46,000 になり、娯楽は 15,000 のまま |
| 使わない | 「今回は使わない」→ 設定 →「これまでの実績から提案」 | カードが消え、予算は 40,000 のまま。設定からはいつでも提案を開ける |

- ログイン、AI分析、iPhone自動記入、Supabase への保存は、本物のサービスが必要なので対象外です（計算部分は Vitest で確かめています）。
