# 計算のテスト（Vitest）

## 期間（月の始まり）`period.test.ts`

| 対象 | 確認していること |
| --- | --- |
| 月の始まりの日 | 1〜28日の範囲に収まる（0→1、31→28、文字や不正値→1） |
| 1日始まり | 期間がカレンダーの月と同じ。2月末（うるう年は29日）まで。期間の表示は出さない |
| 給料日始まり：どの期間か | 5日始まりなら 10/4 は9月、10/5〜11/4 は10月。年をまたぐ場合（1/4→前年12月）も正しい |
| 給料日始まり：始まりと終わり | 10月は 10/5〜11/4、12月（25日始まり）は 12/25〜1/24 |
| 給料日始まり：日数と何日目か | 期間の長さは始まる月と同じ日数。10/5 が1日目、11/4 が31日目。28日目の日付が 11/1 |
| 期間の表示 | 日本語は「10/5〜11/4」、英語は「10/5–11/4」 |
| 今の期間 | 今日が 10/3 なら、1日始まりは10月、5日始まりは9月 |

## 集計 `stats.test.ts`

| 対象 | 確認していること |

| 月の集計 | 収入、予算内の支出、固定費、予算外の支出を分けて合計する。支出の合計はこの3つの和 |
| 月の集計：固定費 | 固定費がない月は前の月の固定費を引き継ぐ。設定を渡さないと固定費は入らない |
| 月の集計：カテゴリ別 | 全支出のカテゴリ別（固定費込み）と、予算内の支出だけのカテゴリ別が正しい |
| 月の集計：給料日始まり | 3日始まりなら 9/30 と 10/2 が同じ期間に入る |
| 予算の合計 | 変動費のカテゴリだけを足す（住居などの固定費カテゴリは入らない） |
| 今日使える額 | （予算 − 今日以外の支出）÷ 残り日数。今日の支出では今日の額は変わらない |
| 今日使える額：明日以降 | 今日の支出を引いた残りを、明日からの日数で割る |
| 今日使える額：先の日付の記録 | 先の日付で入れた支出は、先に予算から差し引く |
| 今日使える額：予算オーバー | 0 より下にならない |
| 今日使える額：期間の最終日 | 残り全額が今日の額。明日以降の額は 0 |
| 予算外の支出 | 今日使える額には影響せず、別に数える |
| 月の経過割合 | 過去の月は1、未来の月は0、今月は経過日数の割合 |
| ペースの色（緑・黄・赤） | 経過割合より8%以上早いと注意、予算を超えると赤 |

| よく使う記録の候補 | メモ付きの記録を回数の多い順に並べ、金額は最新のものを使う。メモなしは候補にしない |
| 曜日ごとの平均 | 曜日ごとの平均支出。固定費カテゴリ、予算外、期間より古い記録は入らない |
| 予算ペースのグラフ | 日ごとの累計（予算外は入れない）。過去の月は全日、未来の月は空 |

## 週の予算 `week.test.ts`

| 対象 | 確認していること |
| --- | --- |
| 週の始まり | 月曜始まりなら 10/15（木）の週は 10/12〜、日曜始まりなら 10/11〜。月をまたぐ週も7日 |
| 週の表示 | 日本語は「10/26〜11/1」、英語は「10/26–11/1」 |
| 週の始まりの設定 | 0 か "0" は日曜、それ以外は月曜 |
| 今週使える額 | 週の始まりの時点の「残り予算 ÷ 残り日数」× 7日。週の途中で使っても枠は変わらない |
| 今週使った額 | 週の中の予算内の支出だけ。週より前の支出は枠から先に引く。予算外・収入・翌週の記録は入らない |
| 残りの1日あたり | 今週の残り ÷ 今日を含む残り日数 |
| 給料日をまたぐ週 | 新しい月の日は、新しい月の予算 ÷ その月の日数で数える。給料日始まり（25日）でも正しい |
| 予算を使い切ったとき | 枠は 0、残りはマイナス（オーバー）、1日あたりは 0 |
| 過去と先の週 | 過去の週は全日経過、先の週は経過 0 日 |

## 固定費と貯金 `fixed-savings.test.ts`

| 対象 | 確認していること |
| --- | --- |
| 固定費の引き継ぎ | 一覧がない月は直前の月の一覧を「未払い」にして使う。それより前の一覧がなければ空 |
| 固定費の変更 | 引き継いだ一覧から変更を始め、元の月の一覧は変わらない |
| 古い保存データ | 足りない項目（毎月の貯金など）を既定値で補う |
| 月の貯金額 | その月に入れた額が、毎月の固定額より優先される。固定額は開始月から |

| 毎月の固定額の変更 | 変更前の月は元の額のまま残り、新しい額は今月から。0 にするとオフ |
| 貯金の平均 | 直近3か月のうち、額がある月だけで平均する |

## ホームと記入 `e2e/home.spec.ts`

| テスト | 操作 | 確認していること |
